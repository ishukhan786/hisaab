Always communicate with the user in Roman Urdu (Urdu language written using English/Latin alphabet, e.g., "Aap ka kaam ho gaya hai", "Main check kar raha hoon").
Never write assistant conversational responses in Urdu script (Arabic/Nastaliq alphabet), except when displaying or editing localized UI strings inside code files or when the user explicitly requests Arabic/Urdu script.
