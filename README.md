# حساب — استعمال کی رہنمائی

## 💻 پی سی پر انسٹال اور استعمال کرنے کے طریقے

1. **انسٹالر سے انسٹال کریں (Recommended Setup)**:
   - `dist` فولڈر کے اندر **`Hisaab-Setup-1.4.0.exe`** پر ڈبل کلک کریں۔
   - یہ ایپ آپ کے کمپیوٹر میں انسٹال ہو جائے گی اور ڈیسک ٹاپ (Desktop) پر «حساب» کا شارٹ کٹ بن جائے گا جہاں سے آپ ایک کلک پر چلا سکتے ہیں۔
2. **پورٹ ایبل فائل (بغیر انسٹال کیے چلائیں)**:
   - `dist` فولڈر میں موجود **`Hisaab-Portable-1.4.0.exe`** کو کسی بھی یو ایس بی یا فولڈر میں رکھ کر بغیر انسٹال کیے براہ راست چلا سکتے ہیں۔
3. **فوری ڈیسک ٹاپ رن**:
   - فولڈر میں موجود **`Run Desktop App.cmd`** پر ڈبل کلک کریں۔
4. **براؤزر میں کھولنا**:
   - `Open Hisaab.cmd` یا `index.html` پر کلک کر کے کسی بھی براؤزر میں استعمال کر سکتے ہیں۔

## اندراج اور روزانہ ویو

- جدول میں براہِ راست لکھیں۔ نئی انٹری کے لیے سب سے نیچے ڈرافٹ قطار موجود رہتی ہے یا اوپر «＋ نئی قطار» دبائیں۔
- ہر نئی انٹری اوپر منتخب «رپورٹ کی تاریخ» کے ساتھ محفوظ ہوتی ہے۔
- اوپر تاریخ تبدیل کرنے سے پرانی انٹریوں کی تاریخ خراب نہیں ہوتی؛ صرف اس منتخب دن کا رجسٹر کھلتا ہے۔
- تمام دنوں کی انٹریاں دیکھنے کے لیے **«تمام تاریخیں»** پر ٹک لگائیں، یا **«📅 دورانیہ فلٹر ▾»** دبا کر اپنی مرضی کی تاریخوں کا دورانیہ منتخب کریں۔ جب تمام تاریخیں نظر آ رہی ہوں تو ہر انٹری کے ساتھ اس کی اصل تاریخ دکھائی دیتی ہے۔
- موبائیل اور رقم کے اردو/عربی ہندسے خود انگریزی ہندسوں میں بدلتے ہیں۔
- فونٹ کے `−` / `＋` بٹن («مزید ▾» مینیو میں) پرنٹ اور رجسٹر کا سائز سیٹ کرتے ہیں۔

## شارٹ کٹ کیز (Keyboard Shortcuts)

- `Ctrl + P`: براہ راست پرنٹ کریں۔
- `Ctrl + Z`: غلطی سے حذف شدہ انٹری فوراً واپس لائیں۔
- `Tab`: اگلے خانے پر جائیں؛ آخری خانے پر Tab دبانے سے اگلی نئی قطار خود فوکس ہو جاتی ہے۔

## روزانہ خلاصہ (Daily Summary)

«روزانہ خلاصہ» کا بٹن دبانے پر ایک مکمل خلاصہ ونڈو کھلتی ہے جس میں:
- ہر تاریخ کے کل اندراجات، بقایا، درہم اور روپے کا الگ الگ مجموعہ دکھایا جاتا ہے۔
- کسی بھی تاریخ کی قطار پر کلک کرنے سے براہ راست اسی دن کا رجسٹر فلٹر ہو کر سامنے آ جاتا ہے۔

## پارٹی کھاتے اور علیحدہ صفحات (Party Ledger Tabs)

- **ہر پارٹی کا الگ صفحہ**: رجسٹر کے اوپر پارٹی ٹیبز (`📁 تمام پارٹیاں` اور ہر پارٹی کا مخصوص ٹیب) موجود ہیں۔
- **مخصوص پارٹی پیج**: جب آپ کسی پارٹی کے ٹیب پر کلک کرتے ہیں تو:
  - صرف اسی پارٹی کی اینٹریاں نظر آتی ہیں۔
  - ٹیبل میں سے پارٹی کا کالم خود بخود چھپ جاتا ہے تاکہ نام اور موبائل وغیرہ کے لیے زیادہ جگہ ملے۔
  - کوئی بھی نئی قطار یا انٹری خودکار طور پر اسی کھلی ہوئی پارٹی کے کھاتے میں درج ہوتی ہے (ڈراپ ڈاؤن سے بار بار چننے کی ضرورت نہیں)۔
  - «کل مجموعہ حساب»، پرنٹ اور Excel ایکسپورٹ صرف اسی پارٹی کا ہوتا ہے۔
- «＋ نئی پارٹی» یا «⚙» سے نئی پارٹیاں بنائیں، نام تبدیل کریں یا ہٹائیں۔
- **کرنسی کا انتخاب (پاکستانی روپیہ یا افغانی)**:
  - ہر پارٹی بناتے وقت آپ **درہم + روپیہ (PKR)** یا **درہم + افغانی (AFN)** منتخب کر سکتے ہیں۔
  - موجودہ پارٹیوں کی کرنسی کسی بھی وقت «⚙» سے تبدیل کی جا سکتی ہے۔
  - جب آپ افغانی والی پارٹی کا پیج کھولیں گے تو کالم ہیڈر، پرنٹ اور ایکسل میں خودکار طور پر **«افغانی»** ظاہر ہوگا اور ٹیب پر بھی «افغانی» کا بیج نظر آئے گا۔

## تلاش، تاریخ اور فلٹر

- نام، وصول کنندہ، موبائیل یا مقام سے تلاش کریں۔ پارٹی اور تاریخ کے فلٹر ایک ساتھ کام کرتے ہیں۔
- مجموعہ، پرنٹ اور «Excel ایکسپورٹ» صرف فلٹر والی انٹریوں کا ہوتا ہے۔

## بیک اَپ اور خودکار محفوظگی

- ڈیٹا آپ کے اسی براؤزر میں محفوظ رہتا ہے۔
- **«مزید ▾»** مینیو میں:
  - **بیک اَپ ڈاؤن لوڈ**: مکمل ڈیٹا کی محفوظ JSON فائل ڈاؤن لوڈ کریں۔
  - **بیک اَپ کھولیں**: پرانا یا نیا بیک اَپ بحال کریں۔
  - **خودکار بیک اَپ فائل**: اگر براؤزر اجازت دے تو اپنے کمپیوٹر پر ایک فائل سلیکٹ کر لیں؛ ہر نئی انٹری پر ڈیٹا خود بخود اس فائل میں محفوظ ہوتا رہے گا۔
- سات دن تک بیک اَپ نہ لینے پر یاد دہانی والی پٹی نظر آتی ہے۔

## Excel اور پرنٹ

- **Excel ایکسپورٹ**: فلٹر شدہ یا تمام انٹریوں کی اصل `.xlsx` فائل (رقم عددی فارمیٹ میں اور مجموعے کے ساتھ) حاصل کریں۔
- **پرنٹ**: A4 لینڈ اسکیپ (افقی) پرنٹ۔ غیر متعلقہ بٹن اور خالی قطاریں خود بخود چھپ جاتی ہیں، اور «کل مجموعہ حساب» ہمیشہ مرکز میں اور واضح ظاہر ہوتا ہے۔ پرنٹ پیج کے اوپر رپورٹ کی تاریخ نمایاں ہوتی ہے۔

## External backups and restore preview

Open More > Backup Manager > Select folder to keep automatic JSON snapshots in a USB or synced folder. The app creates `Hisaab-Backups` inside the chosen folder and retains its latest 30 snapshots. This is a count of snapshots, not 30 days. Primary SQLite/local browser storage stays independent. The last successful backup and failures are shown; reconnect the drive and use Retry to recover. Cloud upload completion must be checked in the sync provider's app.

Desktop uses the native folder picker. Web folder backups require a browser supporting the File System Access directory picker (for example Chrome/Edge on a supported secure origin); permission may need to be granted again after restart. Unsupported browsers show an explanation and can still download JSON backups manually. Restore external JSON files through More > Open backup.

Restore confirmation previews the backup title, date range, counts of parties/register/journal entries and cash-count days alongside current record counts. Cancel leaves existing data unchanged; proceeding still requires the existing safety-backup/write checks.

Possible duplicate register entries now have a visible warning with Review and Keep actions. Matching is scoped to the same date and party; keeping a warning is acknowledged for the current session and does not delete or change records.

Web and desktop both expose PDF/PNG receipt actions and Backup Manager from register/journal views. Web PDF opens browser print (select Save as PDF); image copy depends on browser clipboard permission/support. PNG download remains available when copying is unsupported.
